## 🚀 Getting Started with the Mobile App

The complete source code for the **SAARTHI App** is located inside:
`1. App/App Folder`

### Prerequisites
- Node.js (v18 or newer recommended)
- npm or yarn
- Expo Go App on your mobile device (iOS / Android)

### Run the App Locally:
```bash
# 1. Navigate to the App Folder
cd "1. App/App Folder"

# 2. Install dependencies (if not already installed)
npm install

# 3. Start Expo development server
npx expo start -c
```

Scan the QR code displayed in your terminal using the **Expo Go** app to launch and test the application on your phone.
