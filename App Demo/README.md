# App Demo

This directory contains demonstration materials, screenshots, walkthrough guides, and video demonstration links for the **SAARTHI** cultural heritage application.

## 📱 Interactive Demo Information

- **Primary Platform:** React Native / Expo (Android, iOS & Web)
- **Interactive Heritage Sites Featured:**
  - Qutub Minar Complex (Delhi) — Full 360° Panorama Tour & 3D AR Model
  - Deekshabhoomi Stupa (Nagpur) — 360° Stupa Walkthrough & Heritage Stories
  - India Gate (Delhi) — Interactive 3D Model Explorer
  - Ellora & Ajanta Caves (Maharashtra) — High-definition heritage exhibits

## 🎥 Running the Live Demo Locally

To launch and test the application directly:

```bash
# Navigate to the app source code
cd "APP SOURCE CODE"

# Start the Expo development server
npx expo start -c
```

Press `w` to open in your web browser, or scan the QR code with the **Expo Go** app on your iOS/Android phone.
