# Project Documentation

This directory houses all product specifications, technical requirement documents, system design blueprints, and user flows for **SAARTHI**.

## 📑 Contents

1. **Product Requirements Document (PRD):**
   - [SARTHI_PRD.txt](file:///Documentation/SARTHI_PRD.txt) / [SARTHI_PRD.docx](file:///Documentation/SARTHI_PRD.docx)
   - Defines vision, core user personas, key functional modules, accessibility mandates, and acceptance criteria.

2. **Technical Requirements Document (TRD):**
   - [SARTHI_TRD.txt](file:///Documentation/SARTHI_TRD.txt) / [SARTHI_TRD.docx](file:///Documentation/SARTHI_TRD.docx)
   - Technical specifications, data models, state management, storage keys, rendering performance criteria, and AI grounding standards.

3. **System Design (`System Design/`):**
   - Architectural decisions, component hierarchy, client-side caching, and offline-first data structures.

4. **User Flow (`User Flow/`):**
   - End-to-end user navigation flows: Onboarding -> Discovery -> Site Details -> 360° Virtual Tour / 3D AR Model -> AI Heritage Guide -> Itinerary Planner.

5. **API Details (`API Details/`):**
   - Endpoint contracts, data schemas, and external data provider integrations (ASI, OpenStreetMap/Google Maps, Weather).

6. **Assessment (`Assessment/`):**
   - Evaluation criteria, benchmark testing, and project rubrics.
